这不是 API 文档，而是给需求描述用的可视化手册：淡入、交错、弹性、路径、滚动固定、横向滚动、文字解码、拖拽和布局切换。

基础动画

这些是下指令时最常用的词：淡入、滑入、缩放、旋转、交错、数字滚动和路径运动。

淡入 + 上滑

说法：从下方滑入并淡入。

弹性入场

说法：有一点回弹，不要死板。

交错出现

说法：多个卡片依次出现。

数字滚动

0

说法：数字从 0 增长到目标值。

文字揭示

文字逐行出现

说法：标题逐字或逐行出现。

悬浮感

说法：产品截图轻微上下浮动。

路径运动

说法：元素沿着一条线移动。

鼠标跟随

说法：光点跟随鼠标，移动要顺滑。

滚动叙事

这一段展示 pin、scrub、分步骤出现和视觉状态切换。向下滚动时，左侧固定，右侧逐条解释。

横向滚动

指令说法：用户向下滚动，但内容横向移动。

适合作品集

让多个案例像展览墙一样横向展开，信息密度更高。

也适合流程

采购流程、AI pipeline、视频制作步骤都可以用这种方式。

重点是边界

移动端要检查宽度、触发距离和文字是否被挤压。

插件效果

这些效果更像“高级动效词”：Flip、Draggable、ScrambleText。用户不用懂代码，只要说想要的状态变化。

Flip 布局切换

说法：卡片从网格平滑切成列表。

Draggable 拖拽

说法：这个卡片可以拖动，并限制在容器内。

ScrambleText 解码

GSAP EFFECTS

说法：标题像乱码解码一样出现。

ScrollTo 平滑跳转

跳到顶部

说法：点击按钮平滑滚到指定区域。

首屏标题分层入场；

最后 CTA 聚焦收尾。

不会描述时就这样说

你不需要背 API，只要说清楚“触发时机 + 元素 + 动作 + 状态”。

触发时机：页面打开 / 滚动到这里 / 鼠标悬停 / 点击后
元素：标题 / 卡片 / 图片 / SVG / 数字 / 按钮
动作：淡入 / 滑入 / 缩放 / 固定 / 横向移动 / 解码 / 拖拽
状态：依次出现 / 跟随滚动 / 有回弹 / 最后停在完整位置
