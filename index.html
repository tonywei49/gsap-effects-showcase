先看能力地图 看 Agent 话术
gsap-core

Core Tween 基础补间

淡入、滑入、缩放、旋转、弹性、stagger、数字滚动。适合 UI 元素入场和微交互。

gsap-timeline

Timeline 时间线编排

多个动作按标签、相对位置和重叠关系编排。适合首屏、产品流程、结尾 CTA。

gsap-scrolltrigger

ScrollTrigger 滚动触发

滚到某一段才开始动，也可以固定一屏，让内容跟着滚动慢慢变化。

gsap-plugins / Flip

Flip 布局状态切换

网格变列表、卡片展开详情、筛选重排、拖拽后回位。重点是“前后状态变化”。

gsap-plugins / Draggable

Draggable + Inertia 拖拽惯性

可拖动卡片、旋钮、滑块、看板、抛掷惯性。适合需要真实手感的交互。

SVG 动效

SVG 轨迹和形变

元素沿路径走、线条描边出现、图标从一个形状变成另一个形状。

SplitText / ScrambleText

文字切分和解码

逐字、逐词、逐行入场，或乱码解码。适合标题、口号、章节切换。

Observer

滚轮、触摸、指针手势

统一处理 wheel、touch、pointer。适合滑动切页、方向识别、手势导航。

@gsap/react

React / Next 正确用法

适合组件页面。动画只影响当前组件，页面切走后要自动停掉。

跟 Codex / Agent 正确描述

        
Agent 最怕“你帮我做高级一点”。正确方式是给效果名、触发时机、目标、边界和验收标准。

      

      

        

          
1. 说效果名

          
直接点名能力，比形容词靠谱。

          用 GSAP ScrollTrigger 做 pinned scroll story，左侧固定，右侧步骤驱动状态变化。
        

        

          
2. 说触发时机

          
页面加载、滚到视口、点击、hover、拖拽、滚轮方向，都要明确。

          卡片滚到视口 80% 时 stagger 淡入；返回上滚时不要重复播放。
        

        

          
3. 说技术边界

          
React 项目要说清楚动画只在当前组件里生效；静态页要说加载失败时直接提示。

          这是 React 页面，动画只作用在这个组件里，页面切走后要自动清理。
        

        

          
4. 说验收标准

          
要求浏览器实测，不要只看代码。

          桌面和手机都要截图检查；滚动动画不能空白、不能遮住文字、不能横向溢出。
